# AppFactory run context

This directory is a **factory-authored mirror** of the producing AppFactory run
(`runs/<run_id>/`), excluding caches and the product source tree (the rest of
this repository).

It exists so package-repair workbenches and agent-evolution tooling can load a
single GitHub repo and still see:

- goal / acceptance policy / state
- progressive PM docs (`stages/pm_docs/**`)
- key frames / slot assets (`stages/pm_visuals/**` when present)
- checklist, rewrite, verification, delivery MAPs and evidence
- human report

**Do not treat paths inside this tree as the live product source.** Edit the
Swift / Xcode tree at the repository root. Factory re-sync may overwrite
`appfactory-run/` on later stage completes.

Generated by `bin/factory publish-run-context`.
