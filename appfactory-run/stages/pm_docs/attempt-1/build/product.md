# ThreadGrid · 产品定义

一句话:ThreadGrid 是本地优先、零账号的 iPhone 十字绣图样工作室——导入照片生成可编辑的 DMC 线色格点图,逐格标记绣制进度,导出可打印图解存档。

- category_skeleton: `creation_tool`(在格子上创作/编辑图样;非 log_record_archive)
- ia_shape: `tab_3_to_5`(4 个 task-distinct 主 tab:Charts / Create / Stitch / Threads;Settings 由 Charts 导航进入)
- remote_ai: `no`(见 ai-and-privacy.md;照片转格点是确定性本地图像处理,"照片不出设备"是卖点)

## 用户

十字绣爱好者(英语市场为主):有自己的照片/图想绣,或想把买来的灵感变成可跟踪的图样;讨厌订阅、讨厌崩溃、珍视 DMC 线色的准确性。设备上可能同时有网页版 Stitch Fiddle 的免费习惯——我们赢在原生手感与可靠,不拼免费数量。

## 核心回路

1. **Create**:相机拍一张或从相册选一张照片(也可空白格子起稿)→ 调图样尺寸(格数)与线色数 → 预览 DMC 格点图 → 命名保存(60 秒内从照片到图样)。
2. **Edit**:格点编辑器里逐格改色、整色替换、橡皮、撤销;符号自动按色分配。
3. **Stitch**:绣制模式逐格标记完成,按颜色/符号过滤高亮"当前线",进度环实时更新;完工标记 finished,可拍一张成品照绑到图样。
4. **Export/回访**:导出成果图卡到相册(免费)或可打印图解 PDF(含符号图 + DMC 线量清单,消耗 1 枚 Export Credit);图样入库,下次开新图或再做。

## 差异化(wedge)

- **三段一体**:可靠创建(显式尺寸/色数控制)+ 可信进度(格子是一等数据,不依赖 PDF 符号识别)+ 按幅付费的打印导出。iOS 上没有一家同时在场。
- **本地零账号**:照片与图样不出设备;无注册、无云、无订阅。
- **DMC 真色对照**:量化目标色域是真实 DMC 绣线色卡,预览即所得。

## 市场供给与立场(proceed_narrow_wedge 必选节)

竞争带:关键词空间拥挤,但拥挤来自 color-by-number 游戏(Cross-Stitch: Coloring Book, trackId 1499339385 等,Games 类目,非本 job);功能性工具带是碎片化的弱在位。

- **不与 Stitchly(trackId 1467867656)竞争**:免费生成数量与社交向功能;它崩溃史与尺寸上限我们不碰——我们的立场是"可靠与可编辑",不是"免费更多"。
- **不与 Markup R-XP(trackId 1559524491)竞争**:PDF 商业图纸的符号识别跟踪(它的技术路线与泥潭);v0 不做 PDF 图纸导入(见 non-goals)。
- **不与 Magic Needle(trackId 1323730066)竞争**:一次性照片转换;转换只是我们的第一步,不是全部。
- **只在这件事上竞争**:iOS 原生、可信、从创建到绣完到打印的完整工作室。

## 硬边界

- 本地零账号:无注册、无云同步、无社交分享、无社区。
- 无远程 AI(图像处理全部端上确定性算法);无订阅、无 Restore Purchases(消耗制)。
- 不做 PDF 图纸符号识别导入(v0);不做 color-by-number 游戏;不做 knitting/crochet。
- 照片媒体回路完整:相册读(导入)+ 相机拍(建图/成品照)+ 相册写(导出图卡),权限被拒一律应用内继续,不跳系统设置。
