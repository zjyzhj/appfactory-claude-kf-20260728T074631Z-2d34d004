# ThreadGrid · v0 非目标(明确不做)

## 市场立场镜像(proceed_narrow_wedge)

- **不做 PDF 商业图纸导入/符号识别**——那是 Markup R-XP(trackId 1559524491)的路线与泥潭;我们的格子是一等数据,不解析第三方 PDF。
- **不拼免费生成数量/不做社交**——不追 Stitchly(trackId 1467867656)的广度;我们卖"可靠 + 可编辑 + 可打印"。
- **不做一次性转换器**——Magic Needle(trackId 1323730066)式的"转完即走";转换只是我们回路的第一步。

## 产品与功能

- 无账号、无云同步、无多设备、无社交分享/社区/图样商城。
- 无远程 AI(无聊天、无生成式建议);图像处理全部端上确定性算法。
- 不做 color-by-number 游戏化;不做 knitting / crochet / diamond painting(v1+ 候选)。
- 不做刺绣机文件导出(DST/PES);不做图样导入(zip/pdf/image 识别导入均不做)。
- 无推送通知、无小组件、无 Apple Watch、无 iPad 专属布局(可运行不优化)。
- 无订阅、无 Restore Purchases(消耗制点数);不做广告、不做 ATT、不用麦克风。

## 技术

- 不引入第三方分析/崩溃 SDK(v0);不引入网络图片 CDN(DMC 色库内置 bundle)。
- 不做 iCloud/Handoff;数据迁移(导出/导入图样工程文件)留待 v1 评估。
